# 공짜맵 (freemap-kr)

전국 **무료주차장**을 지도로 보여주는 정적 사이트.
공공데이터를 미리 받아 HTML/JSON으로 구워두기 때문에 서버가 필요 없고,
Cloudflare Pages에 그대로 올리면 끝난다.

```
data/raw/parking.json  공공 API 원본 (git에 안 올라감)
        ↓ scripts/build_site.py
dist/                  배포되는 결과물 전체 (Cloudflare Pages가 이 폴더만 서빙)
```

생성되는 페이지

| 경로 | 내용 |
|---|---|
| `/` | 전국 통계 + **내 주변 찾기**(위치 기반) + 시도 목록 |
| `/서울특별시/` | 시군구 목록 |
| `/서울특별시/강남구/` | 지도 + 목록 (검색 유입을 받는 실제 페이지, 약 250개). 주차면수 많은 순 |
| `/data/서울특별시/강남구.json` | 그 지역 데이터만 담은 조각 (필요할 때만 내려받음) |

## 1. 공공데이터포털 인증키 발급

1. https://www.data.go.kr 회원가입
2. [전국주차장정보표준데이터](https://www.data.go.kr/data/15012896/standard.do)에서
   **[오픈 API] 탭 → [활용신청]** (자동승인, 즉시 사용 가능)
3. 마이페이지 → 오픈API → 인증키에서 **일반 인증키(Decoding)** 복사

> **개발계정만으로 충분하다.** 일일 트래픽 1,000건은 레코드 수가 아니라 *호출 횟수*이고,
> 이 스크립트는 한 번에 1,000건씩(`numOfRows=1000`) 받으므로 전국 주차장 약 2만 건을
> 20~30회면 다 가져온다. 갱신도 한 달에 한 번이라 한도에 걸릴 일이 없다.
> (운영계정으로 전환하면 하루 10만 건까지 늘어나지만 여기서는 필요 없다. 전환·이용 모두 무료.)

## 2. 로컬에서 돌려보기

**`실행.bat` 을 더블클릭한다.** 처음 한 번만 인증키를 물어보고(`data/.key`에 저장),
데이터 수집 → 사이트 생성 → 브라우저 열기까지 알아서 진행한다.
인증키를 잘못 넣었으면 `data/.key` 파일을 지우고 다시 실행하면 된다.

직접 명령으로 하고 싶다면:

```bash
$env:DATA_GO_KR_KEY="발급받은_디코딩_인증키"
python scripts/fetch_data.py
python scripts/build_site.py
python -m http.server 8788 --directory dist
```

키 없이 화면만 먼저 보고 싶으면:

```bash
python scripts/make_sample.py
python scripts/build_site.py
```

API 응답 필드명이 바뀐 것 같으면 첫 레코드를 그대로 찍어볼 수 있다:

```bash
python scripts/fetch_data.py --probe parking
```

## 3. Cloudflare Pages 연결

GitHub에 올린 뒤 Pages에서 저장소를 선택하고:

| 항목 | 값 |
|---|---|
| 프레임워크 프리셋 | None |
| 빌드 명령 | **(비워둠)** |
| 빌드 출력 디렉터리 | `dist` |

`dist/`가 저장소에 커밋되어 있으므로 Cloudflare는 빌드를 돌리지 않고 파일만 올린다.
빌드 실패로 사이트가 깨질 일이 없고 배포도 몇 초면 끝난다.

## 4. 매달 자동 갱신 (GitHub Actions)

`.github/workflows/update.yml` 이 매월 2일 새벽에 데이터를 다시 받아
`dist/`를 커밋하고, 그 커밋을 Cloudflare Pages가 자동 배포한다.

저장소 Settings에서 아래를 등록한다.

**Secrets** (Actions → Secrets)
- `DATA_GO_KR_KEY` — 공공데이터포털 디코딩 인증키
- `SEOUL_API_KEY` — 서울 열린데이터광장 인증키 (없으면 서울 수집 단계를 건너뛴다)

**Variables** (Actions → Variables)
- `SITE_URL` — 예: `https://gongjjamap.com` (canonical·사이트맵에 쓰임, 도메인 붙인 뒤 꼭 설정)
- `ADSENSE_CLIENT` / `ADSENSE_SLOT_TOP` / `ADSENSE_SLOT_FEED` / `ADSENSE_SLOT_BOTTOM`

## 5. 애드센스

### 설정

애드센스 승인 후, 광고 단위 3개(모두 **디스플레이 광고 / 반응형**)를 만들고
슬롯 ID를 위 Variables에 넣으면 다음 빌드부터 광고가 붙는다.
값이 비어 있으면 광고 태그와 `ads.txt`를 아예 만들지 않으므로,
승인 전에는 그냥 두면 된다. `ads.txt`는 `ADSENSE_CLIENT` 값으로 자동 생성된다.

### 지면 배치

| 슬롯 | 위치 | 의도 |
|---|---|---|
| `TOP` | 지도 바로 아래, 목록 위 | 첫 화면에서 시선이 지도 → 목록으로 내려가는 길목. 지도 위가 아니라 아래에 둬서 핵심 콘텐츠를 가리지 않는다 |
| `FEED` | 목록 5번째 항목 뒤 (JS로 삽입) | 스크롤이 가장 오래 머무는 구간 |
| `BOTTOM` | 목록 끝, "다른 지역" 링크 위 | 다음 행동 직전의 마지막 노출 |

정책·수익 관점에서 이렇게 처리해 뒀다.

- **피드 광고는 페이지당 한 번만 요청한다.** 목록이 다시 그려질 때마다 새 광고를
  호출하면 무효 트래픽으로 잡힐 수 있다.
- **항목이 3개 미만인 지역 페이지는 광고를 넣지 않고 `noindex` 처리**하고 사이트맵에서도 뺀다.
  내용이 거의 없는 페이지에 광고를 붙이는 것이 애드센스에서 가장 흔한 거절 사유다.
- **`.ad-slot`에 `min-height:130px`** 을 줘서 광고가 늦게 뜰 때 목록이 밀리지 않게 했다(CLS 방어).
  코어 웹 바이탈이 나빠지면 검색 노출과 수익이 같이 떨어진다.
- 광고 위에 작은 `광고` 라벨을 붙였다. 목록 카드와 광고가 섞여 보이는 것을 막아
  실수 클릭(정책 위반)을 줄인다.
- 애드센스 스크립트는 `async`로만 넣어 지도와 데이터 로딩을 막지 않는다.

### 승인 전략

지역 페이지 250개가 한 번에 생기지만, 승인 심사는 **홈 + 대표 지역 몇 개**를 본다.
`build_site.py`의 “이 지역 이용 안내” 문단이 각 페이지의 고유 텍스트 역할을 하니,
지역별로 한두 문장씩 다르게 써 주면 통과 확률이 올라간다.
개인정보처리방침 페이지는 애드센스 필수 요건이므로 승인 신청 전에 추가할 것.

## 6. 공유 버튼

모든 페이지(홈 / 시도 / 시군구) 하단에 공유 영역이 있다.

| 버튼 | 동작 |
|---|---|
| 공유하기 | `navigator.share` — **모바일에서만 자동으로 나타난다.** 기기의 공유 시트가 열려 카카오톡·문자·인스타그램이 전부 잡히므로 카카오 SDK와 앱키가 필요 없다 |
| 주소 복사 | 클립보드 복사 + 토스트. 권한이 거부되면 구형 방식(`execCommand`)으로 한 번 더 시도한다 |
| 네이버 블로그 / X / 페이스북 | 각 서비스의 공유 창을 팝업으로 연다 |

주소가 한글이라 `location.href`는 `%EC%84%9C...`로 인코딩돼 있다.
복사·공유 시트에는 `decodeURI()`로 되돌린 주소를 넘겨 카톡에 붙여넣어도 한글로 깔끔하게 보인다.
(네이버·X·페이스북 공유창에는 인코딩된 원본을 그대로 넘긴다.)

나중에 카카오톡 전용 공유 버튼(썸네일·설명이 붙은 카드형)이 필요해지면
[Kakao JavaScript SDK](https://developers.kakao.com) 앱키를 발급받아 도메인 제한을 걸고
`app.js`의 `bindShare()`에 케이스 하나만 추가하면 된다. 초반에는 없어도 된다.

## 7. 손볼 만한 곳

- `scripts/build_site.py` → `build_region_page()` 안의 본문 문구, 제목 패턴
- `static/style.css` → 색상은 `:root` 변수 두 벌(라이트/다크)만 고치면 된다
- `static/app.js` → 목록 표시 개수(300), 내 주변 반경(가까운 시군구 3곳)
- 지도 타일은 OpenStreetMap(무료·키 불필요). 카카오맵으로 바꾸려면 JS 키를 발급받아
  도메인 제한을 걸고 `app.js`의 `initMap()`만 교체하면 된다.

## 데이터 출처

두 곳을 합쳐 쓴다. 서울 데이터는 표준데이터와 같은 필드명으로 변환해 저장하므로
`build_site.py` 는 두 파일을 그냥 이어붙인다.

| 출처 | 받는 것 | 인증키 |
|---|---|---|
| 공공데이터포털 「전국주차장정보표준데이터」 | 전국 약 1.9만 건 | `DATA_GO_KR_KEY` |
| 서울 열린데이터광장 `GetParkInfo` | 서울 공영주차장 2,186건 | `SEOUL_API_KEY` |

### 왜 서울만 따로 받나

표준데이터에 등록된 서울 무료주차장이 **15곳**뿐이었다. 서울시는 자체 시스템으로
공영주차장을 관리해서 표준데이터에 요금 정보를 거의 올리지 않는다.
열린데이터광장을 붙이면 서울이 **1,426곳**이 된다. 좌표는 86%가 채워져 있어
지오코딩은 필요 없다.

### 상시 무료 / 요일별 무료

서울 공영주차장은 **상시 무료가 4.6%뿐이고, 93%가 토요일에 무료**로 풀린다.
그래서 두 가지를 모두 싣되 반드시 구분한다.

- 상시 무료: 초록 마커, `무료` 칩, 목록 위쪽에 정렬
- 요일별 무료: 주황 마커, `토요일 무료` / `공휴일 무료` 칩,
  카드마다 "평일에는 요금을 받습니다" 문구, 목록 아래쪽에 정렬
- 조건부가 섞인 지역 페이지에는 상단에 경고 문단이 붙는다

판정은 `normalize_parking()` 의 `fl` 필드가 한다. 비어 있으면 상시 무료다.

### 공중화장실을 뺀 이유

「전국공중화장실표준데이터」도 함께 쓰려 했으나 제외했다.
**2025년 2월 원천데이터 정책 변경으로 WGS84 위도·경도 항목의 제공이 중단**되어
지도에 찍을 좌표가 없다. 주소만 있으므로 넣으려면 5만 건을 지오코딩해야 하는데,
그만한 값어치가 없다고 판단했다. 나중에 다시 붙이려면 카카오 로컬 API
(주소→좌표, 일 10만 건 무료)로 변환한 뒤 결과를 캐시하면 된다.
현장 운영 상황과 다를 수 있으므로 사이트 하단에 안내 문구를 넣어 두었다.
