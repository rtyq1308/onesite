전체 예상 수익 $1.10 / 광고 노출 380 / 노출 RPM $2.89 / Active View 48.39%.
모바일 전면: $0.71, 77회, RPM $9.25, Active View 80.77%.
앵커: $0.27, 150회, RPM $1.80, Active View 86.08%.
인페이지: $0.09, 152회, RPM $0.62, Active View 14.29%.
광고 의도 칩: 1회로 단가 판단에서 제외. 각 행 수익은 반올림되어 합계와 차이 가능.
노출 RPM은 페이지 RPM이 아니다. 세션/페이지뷰가 없으므로 방문자당 수익은 아직 계산 불가.

## 이번 변경
- 결과 3개 뒤에 고정된 DOM 광고 슬롯 1개. 목록 재검색/필터/지도 이동에도 광고를 삭제하거나 새로 요청하지 않는다.
- 슬롯이 화면에 절반 이상 들어오면 페이지당 한 번 요청. 광고 채우기 실패(unfilled) 시 빈 슬롯 숨김.
- 기존 자동 앵커/전면 설정 유지. 지도/버튼 위 광고 추가 없음.
- GA4 이벤트: ad_slot_request(placement,version), ad_slot_result(placement,result), results_sheet(expanded).
이 이벤트는 요청/슬롯 상태 진단용이며 AdSense 실제 노출·Active View·수익을 대신하지 않는다. GA 차단/미설정 시 수집 안 됨.

## 매주 같은 요일 운영
1. AdSense에서 날짜·사이트·기기·광고 형식별 수익, 노출, Active View를 내보내 revenue-weekly.csv에 입력.
2. GA4에서 세션/페이지뷰와 기존 길찾기 이벤트 수를 입력. 이벤트명은 GA4 이벤트 목록 확인. 필요하면 placement/result/version을 이벤트 범위 맞춤 측정기준으로 등록.
3. 세션당 수익 = 수익/세션, 페이지 RPM = 수익/페이지뷰*1000, 길찾기/세션 = 길찾기/세션. 분모 0이나 미확인 값은 공란.
4. 이번 변경을 최소 14일 유지. 같은 기기·유입 구성으로 비교. 380회 규모에서는 며칠 수익만으로 승자 결정 금지; 비교 기간 각 1,000회 미만이면 방향성만 기록(통계적 유의성 기준은 아님).
5. 가시성 향상만으로 성공 판단하지 않는다. 세션당 수익 상승과 길찾기/세션·재방문 유지 여부를 함께 본다. 기능 이용률이 10% 이상 악화하면 원인 점검 후 배치 되돌림 고려(운영 경계값).

## 사용자가 AdSense에서 진행할 설정
Ads > 사이트 편집의 실험 기능에서 자동 광고 설정을 한 번에 하나만 비교한다.
먼저 이번 배치 기준선 확보 후, 앵커 상단/하단 또는 광고량 중 하나를 실험. 전면 광고 빈도는 현재 값 기록 후 사용자 이탈을 함께 비교.
계정 설정 변경과 GA4 연결은 사용자가 진행. 이 작업에서 계정 설정을 변경하거나 수익 API를 연결하지 않았다.
