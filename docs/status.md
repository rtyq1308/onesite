# 진행 상태 — 2026-09-09

## 네이버 지도·목적지 검색

- `static/app.js`의 Leaflet/OSM 지도 코드를 네이버 Maps SDK로 전환했다. 지역 묶음 마커, 확대 후 개별 무료·요금 마커, 상세 팝업, 목적지/현재 위치 표시를 연결했다.
- 홈과 시군구 페이지에 목적지 검색창을 추가했다. 장소명은 Pages Function을 통한 네이버 지역 검색, 주소는 지도 Geocoder를 사용한다. 목적지 선택 후 인근 8개 지역의 주차장을 직선거리순 최대 300곳 표시한다.
- 인증정보 누락·외부 검색 실패·오래된 검색 응답·입력 마크업을 처리한다. 기존 무료 필터에서 0건일 때 문구를 수정했다.
- 일반 빌드는 지도 ID가 없으면 dist를 건드리기 전에 차단한다. 미리보기는 별도 `.preview`에 만들고 광고를 제거한다. 검색용 비밀키 파일은 생성하지 않았다.
- 테스트: Node 자동 테스트 10개 통과. API 입력/인증 누락/좌표 정규화/외부 실패, 검색 결과 선택/목록 정렬/필터/문자열 안전 처리/오래된 응답 무시/주소 검색, SDK 모형을 사용한 마커·팝업·목적지 표시 수명 검증.
- 미리보기 242페이지 빌드 완료. 데스크톱 및 390×844 브라우저에서 검색창 레이아웃과 연결 전 실패 안내를 확인했다. 실제 모바일 기기 검증은 아니다.
- 미완료: 사용자 네이버 Maps·검색 API 설정, 실제 SDK 타일과 실검색 성공 검증, Cloudflare Functions 배포 및 배포 후 검증. 실제 인증 없이 SDK 모형 테스트를 통과한 것이므로 실서비스 완료로 간주하지 않는다.
- 운영 dist와 온라인 사이트는 변경하지 않았다. Git 커밋·push·배포를 수행하지 않았다.
- 알려진 별도 과제: 주차면/시설 집계 중복 의심, 지도 중심 전체 레이아웃 개편. 이번에 변경하지 않았다.

연결 절차: [naver-map-setup.md](naver-map-setup.md).
- 마지막 검사: 일반 빌드가 지도 ID 누락으로 의도대로 종료됨을 확인했고 `git diff --check`에서 공백 오류가 없었다.
- 작업 종료 시 별도 변경으로 보이는 `dist/assets/app.js`의 `window.__map` 노출 1줄을 발견했다(이번 작업에서 작성하지 않음). 해당 변경은 덮어쓰거나 되돌리지 않았다. 이번 네이버 전환 코드는 static 소스와 .preview에만 반영했다.

- 로컬 1280×720/390×844 브라우저에서 배치 및 모바일 목록·메뉴 조작 확인. 로컬 도메인은 Naver 지도 인증 제한이 있어 지도 배경과 실제 검색은 운영 배포 후 확인한다.

### 운영 검증 결과
- 84d71ca0 및 광고 높이 보완 43edc773을 origin/main에 push했고 운영 HTML/CSS 반영을 확인했다.
- 실제 광고 로딩 시 반응형 광고가 상위 패널에 height:auto !important를 삽입하는 문제를 발견해 목록 광고를 300×250 고정 슬롯으로 변경했다.
- body가 앵커 광고 높이만큼 padding을 받을 때 지도 영역이 남은 화면에 맞춰 줄어들도록 flex 구조로 보완했다.
- 운영 390×844: 지도 타일 표시, 목록 접힘 174px/펼침 516.75px, 지역 메뉴 정상 확인. 운영 1280×720: 하단 광고 padding 120px 상태에서 지도/목록 작업영역 538px로 정상 유지 확인.
- 실제 도로명 주소 검색(서울 중구 세종대로 110)은 Naver 주소 대체 경로로 성공했고 주소 선택 후 주변 주차장 300곳을 불러왔다.
- 미완료: /api/places 장소명 검색은 운영에서 503(search_unavailable). 코드상 NAVER_SEARCH_CLIENT_ID 또는 NAVER_SEARCH_CLIENT_SECRET이 실행 환경에 전달되지 않은 경우다. 사용자가 Cloudflare 실제 Pages 프로젝트의 Production 변수 적용을 확인해야 한다. 인증값은 조회·출력하지 않았다.
- 광고 RPM/노출 가시성 개선 여부, 실제 휴대폰 위치 권한 및 외부 지도 앱 전환은 이번 검증 범위 밖이다.
